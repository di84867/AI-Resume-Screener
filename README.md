🏗️ Core Frameworks & Language

Python: The primary programming language used for all backend logic and AI integration.
Streamlit: A high-performance, Python-native web framework used to build the responsive, dark-themed user interface.
🧠 Artificial Intelligence & NLP
LangChain: Orchestrates the integration of multiple Large Language Models (LLMs).
LLM Providers: Support for OpenAI (GPT), Google Generative AI (Gemini), and HuggingFace for semantic analysis, resume rewriting, and mock interviews.
spaCy: Used for advanced Natural Language Processing, such as entity recognition and feature extraction from resumes.
Sentence-Transformers: Implements semantic matching for computing the similarity between resumes and job descriptions.

📊 Data Analysis & Visualization
Pandas & NumPy: The backbone for data manipulation and numerical processing of candidate scores.
Plotly: Generates the interactive, "premium" charts used for match distribution analysis and analytics.
NetworkX: Used to create complex "Skill Network" visualizations.
Scikit-learn: Provides machine learning utilities for ranking and analysis.

📄 Document & Resume Processing
PyPDF: Extracts text and metadata from uploaded PDF resumes.
PyLaTeX & LaTeX: Powers the "Resume Studio" to generate professional, industry-standard LaTeX resumes.
xhtml2pdf: Converts HTML-based resume templates into downloadable PDFs.

🎙️ Audio & Voice Intelligence
gTTS (Google Text-to-Speech): Provides a vocal personality ("Natalia") for the mock interview feature.
SpeechRecognition: Enables users to provide voice answers during interviews, converting speech to text for AI feedback.

🚢 Infrastructure & Deployment
Docker: Containerization via Dockerfile and docker-compose.yml ensures consistent environments across development and production.
Venv: Python virtual environment for localized dependency management.

✨ Design Aesthetics
The UI utilizes a Custom CSS Design System (embedded in app.py) featuring:
Google Fonts (Outfit) for premium typography.
Glassmorphism effects for cards and overlays.
